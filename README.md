<p align="center">
  <b>Thin controllers</b> validate input and map HTTP to services.<br/>
  <b>Services</b> own the business rules, so they are easy to test.<br/>
  <b>Repositories</b> hide schema design and query optimization behind a clean interface.<br/>
  <b>Stateless JWT auth</b> keeps the API secure and horizontally scalable.
</p>
